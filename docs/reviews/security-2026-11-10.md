## Manual read, no finding

- **API reach.** It binds to `127.0.0.1`. `TrustedHostMiddleware` blocks DNS rebinding, and a request with a foreign `Origin` gets 403. CORS allows one origin.
- **Media route.** Names must match `^\d+-[0-9a-f]{32}\.(png|jpg)$`, so no path can leave `journal_media/`.
- **Workflows.** No `${{ github.event... }}` text reaches a shell. `publish.yml` has read-only contents. `collect.yml` and `forecast.yml` need `contents: write` to push the `data` branch.
- **Tracked files.** No keys, tokens, `.env`, journal database, journal media or email address in git.

## Whole-repo code review

`/code-review` over `src/` and `web/src/` after the scan. None of these is a security problem. All seven are fixed, each with a test that failed first.

| # | Where | Finding |
|---|---|---|
| 1 | `journal/store.py:118` | A journal row whose symbol was later removed from `symbols.toml` makes `/journal` and `/journal/stats` return 404 for every row. |
| 2 | `api/main.py:153` | The app-wide `ValueError` to 422 and `KeyError` to 404 handlers also catch internal bugs, so a server fault looks like bad input. Finding 1 is one case. |
| 3 | `api/main.py:287` | Replacing a screenshot or deleting a trade leaves the old image in `journal_media/`. |
| 4 | `strategy/walk.py:38` | A trade opened at or after 16:00 ET never auto-closes, even after its stop is hit. |
| 5 | `journal/store.py:118` | `symbols.toml` is read and parsed once per journal row. |
| 6 | `journal/trades.py:57` | Two "Take trade" requests arriving together can both pass the one-open-trade check. |
| 7 | `export/snapshot.py:101` | A local export doesn't clear the output folder, so a file from an earlier run stays when today's export of it fails. The nightly job starts clean. |

Notes on the fixes:

- **2:** only the `KeyError` handler was narrowed, to the journal's own `NoSuchEntry`. The `ValueError` handler stays, because the code uses `ValueError` for refusals the rail shows to Vaughn, such as "MES: 10 usable sessions".
- **4:** a trade opened at or after 16:00 ET is now flat at 16:00 ET the next day. Trades opened earlier keep the same-day rule the backtest uses.
- **7:** the exporter removes the one file whose export failed. It doesn't wipe the output folder.
